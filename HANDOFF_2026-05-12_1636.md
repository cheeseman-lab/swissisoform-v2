## Context to Remember

- **GPU blocker**: `cheeserind` is on the local `wibrcluster` SLURM (CPU-only `20`/`u20` partitions). The WI cluster GPU partitions live behind `/nfs/config/slurm-wibr/slurm.conf` and aren't reachable via federation from cheeserind. Workaround: ssh to a head node that's a WI cluster login (Matteo to set up key) and run `ssh wibr-login sbatch ...` from `run_full.sh`.
- **`nvidia-A100-20` is commented out** in the WI slurm conf — use `nvidia-A6000-20` (3 GPUs/user, 768G mem) or `nvidia-L40S-20`.
- **Cache pattern (Pattern 2)**: precompute writes per-protein file keyed by sha1 of stop-stripped, uppercased sequence. Pipeline-side module does hash-keyed lookup, returns `status="no_cache"` if missing — never blocks the pipeline.
- **Compute pattern audit**: CPU-heavy tools (InterProScan, DeepLoc, SignalP, TargetP, PepQuery) still use Pattern 1 (inline subprocess, no cache). Fine for 5-gene E2E. Will NOT scale to 6 cell lines × 9k genes — needs Pattern 2 retrofit.
- **F1 (structured extension)** activates when `plddt_diffregion_mean > 70`. **F5 (pathogenic variant enrichment)** activates on PLM VEP output.
- **`run_sample` signature**: takes positional file path, not `ribotish_df=`. Pattern in `build_proteins_fasta.py` mirrors `inspect_e2e.py` — call on full HELA file then filter by `Symbol`.
- **80 TIS across 5 genes** (TP53, EIF4G1, VEGFA, CTNND1, MYC); 87 unique proteins in `data/cache/proteins.fa` (8 over 1024-aa cap will skip fold).
- **`swissisoform-v2-fold` env** exists for fold; **`swissisoform-v2`** for everything else. The PLM precompute can run inside `swissisoform-v2` since the embed module imports torch/transformers lazily — but the sbatch script may need its own env name; verify before submit.
