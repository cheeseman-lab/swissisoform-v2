Pinning ribosomes to the right mRNA

Resolving the true source transcript — and its exact start-codon sequence — for every translation-initiation site, to build the first sequence-to-initiation-efficiency training set.
SwissIsoform v2 · Source-Transcript Resolution · HeLa pilot · 2026-06-17

The goal

We want a model that predicts translation-initiation efficiency from mRNA sequence. That requires each initiation site paired with the sequence that produced it.

Ribo-TISH detects where ribosomes start translating — but it assigns each site to every annotated transcript whose splice structure is compatible, ignoring which mRNAs actually exist in the cell. Each site arrives carrying a polluted cloud of candidate transcripts with divergent 5′UTRs. To train a sequence model, we must collapse that cloud to a single, unambiguous start-codon sequence — or honestly discard the site.

The key realization: we don't need to know which isoform a footprint came from. If every surviving candidate shares the same local sequence around the start codon, the site maps to a unique sequence regardless. We only discard when the local sequence is genuinely ambiguous.

The filtering funnel

The whole workflow is a funnel: from every raw Ribo-TISH call down to the subset whose source mRNA we know unambiguously. Each step removes calls we can't trust or can't resolve — and what survives is the training set.

What we built today

Starting from the HeLa Ribo-TISH calls, we pulled every candidate transcript's mRNA straight from the GENCODE transcriptome (the same reference the RNA-seq mapped against), located each site's start codon inside every candidate, and tested whether the candidates agree in a ±100 nt window. We then layered in HeLa expression (salmon) and discovered the two signals are complementary — their union resolves far more than either alone.

The union strategy

Two independent ways to make a site unambiguous:

① Sequence-window purity. If all candidates are byte-identical within ±W of the start codon, the local sequence is unique — no expression needed, highest confidence.

② Expression resolution. If only one candidate is actually expressed in HeLa, that one is the source; if several are expressed but agree in-window, they're interchangeable.

They cover each other's blind spots: sequence purity handles “all candidates agree”; expression handles “candidates differ, but only one is real.” Taking the union — keep if pure or expression-resolved — is the single biggest lever we found.

Window length is a confidence dial

How far the candidates agree depends entirely on how much sequence you ask for. Near the start codon they almost always match; move outward into divergent 5′UTRs and agreement collapses.

Arm B — long-read results

The long-read arm (HeLa ONT, in-house minimap2 + IsoQuant) is in — and the answer is more nuanced than “long-read wins.” By expression alone it resolves 50.2% of multi-candidate TIS vs salmon's 41.8%, and loses far fewer (1,967 vs 5,111) — confirming that read-dilution recovery is real (one read = one isoform).

But the two unions nearly coincide (long-read 59.3% vs salmon 60.3%), because long-read keeps genuinely co-expressed isoforms and so flags 2,974 sites as honestly ambiguous (vs salmon's 662). The payoff is trustworthiness: ~32% of salmon's single-source calls are likely dilution artifacts (long-read finds >1 expressed isoform there), and salmon's sub-1-TPM calls agree with long-read only 62% of the time.

Decision: long-read is the better HeLa provider — for trustworthiness, not raw count. Use sequence-window purity as the backbone everywhere, long-read existence where available (HeLa, K562), and salmon only where long-read is absent (U2OS, RPE1), flagged lower-confidence.

The three-way union

The three signals are complementary, so we take their union — a TIS is resolved if it is sequence-pure or short-read-resolved or long-read-resolved — but tiered by evidence strength rather than counted flat, because the three don't carry equal weight.
