About SwissIsoform v2

SwissIsoform annotates alternative protein isoforms found by translation-initiation sequencing (Ribo-TISH). Each alternative start codon (TIS) produces a protein that differs from the canonical one in a defined differential region; every page weighs the evidence that that isoform exists and that it does something.

The differential region & reading frame

The differential region is the part of the isoform that is not shared with the canonical protein. Two cases, and the distinction (diff_space) governs which tools are valid:

  • Truncation (diff_space = canonical) — the isoform starts downstream, losing the canonical N-terminus. The lost region is ordinary canonical-coding sequence, so canonical-frame tools (e.g. AlphaMissense) apply.
  • Extension / uORF / alt-ORF (diff_space = isoform) — the isoform starts upstream or out-of-frame, so the gained region is not in the canonical reading frame. Canonical-frame predictors are meaningless here (AlphaMissense reports these positions as "intronic" / N/A); only frame-aware tools (ESM-2 ΔLLR, alt-ORF consequence) apply.

Two evidence axes

Twelve criteria, six per axis. Each returns ✓ (true), ✗ (false), or – (not evaluable) — a criterion whose underlying data could not be computed reports "not evaluable" rather than counting against the isoform. The header score is passed / evaluable.

The metrics behind the criteria

phyloP / phastCons
Per-base evolutionary constraint from the Zoonomia 241-mammal alignment. phyloP scores acceleration/conservation at single sites; phastCons scores the probability a base is in a conserved element. E3 reads the absolute mean phyloP over the differential region — a value above the strong-purifying-selection threshold means the unique coding sequence is itself under constraint. The enrichment versus the shared core is shown as context only; the call does not require the unique region to beat the shared core.
Frame conservation (primate / mammalian)
We extract the differential ORF across primate and mammalian genomes and test whether the reading frame stays intact (no frameshift, no premature stop, start codon preserved). "Phylo depth (MRCA)" reports how deep the deepest still-intact species sits — deeper = older selection on the ORF.
Initiation efficiency & Kozak context
How strongly ribosomes initiate at the alternative start relative to background, per cell line (CPM + p-value). The Kozak context (−9..+4 around the ATG) and its Hamming distance to the consensus indicate whether the sequence favours initiation.
Mass spec
In-silico tryptic digest of the differential region, matched against detected peptides (PepQuery). A peptide unique to the isoform region is direct proof of translation.
pLDDT & structure (Boltz)
Per-residue model confidence (0–100) from a Boltz structure prediction. High pLDDT in the differential region implies it folds into ordered structure rather than disorder. We also report TM-score / RMSD between canonical and isoform folds. A "uniform-pLDDT" status flags a placeholder structure — treat as unreliable.
DeepLoc / SignalP / TargetP
Subcellular-localization (DeepLoc) and N-terminal targeting-signal predictors (SignalP = secretion, TargetP = mitochondrial/chloroplast transit). We run them on canonical and isoform. F2 fires when any DeepLoc localization feature changes — the predicted compartment, the detected sorting signals, or the membrane-association call — so a re-routed protein is caught even when the headline compartment label is unchanged. N-terminal changes most directly add or remove targeting peptides (F4).
InterProScan domains & motifs
Annotated protein domains (InterPro) and short linear motifs that fall inside the differential region. Gaining or losing a domain is a direct functional change.
ESM-2 ΔLLR (sequence constraint)
A protein language model scores how "surprised" it is by each residue (masked- marginal log-likelihood ratio). Averaged over the unique vs shared region, it measures constraint in the isoform's own reading frame — so it works on extensions where AlphaMissense cannot.
AlphaMissense canonical frame only
Precomputed missense-pathogenicity for every canonical-protein amino-acid change. Valid on truncations (canonical-coding lost region), but N/A on extensions — those positions are not in the canonical frame, so AlphaMissense has no score for them. It is also missense-only: it never sees frameshift or stop-gain (loss-of-function) variants, which are assessed separately.
Biophysics
Whole-region physicochemical properties of the differential vs shared sequence: isoelectric point, hydropathy (GRAVY), charge, disorder, low-complexity and prion-like fraction, LLPS / π–π propensity, aromaticity, instability, entropy. A biophysically distinct region is more likely to confer a distinct function (e.g. phase separation).
Clinical & population variants
ClinVar / COSMIC (disease / cancer) and gnomAD (healthy-population) variants intersected with the differential region. We count variants per region and divide by the region's nucleotide length (not amino-acid length) to get a density, then compare the unique region against the shared core. Two directional signals fall out: F5 — germline tolerance & constraint asks whether gnomAD germline variation avoids the unique region (a depletion ratio below 1 means population variation is depleted there, i.e. the region is constrained), reinforced by ESM-2 sequence constraint; and F6 — disease density enrichment asks whether ClinVar / COSMIC disease variants concentrate in the unique region versus the shared core (an enrichment ratio at or above 1). gnomAD is a tolerance catalogue and feeds F5 only; it never counts as disease burden. Loss-of-function consequences (frameshift, stop-gain) are clinically relevant independently of any missense pathogenicity score.

How a criterion is decided

Every criterion follows the same four-step shape, so the table reads consistently across all twelve:

  1. Claim — the criterion states one falsifiable thing about the isoform (e.g. "the differential region is under coding-level purifying selection").
  2. Canonical-vs-isoform comparison — the same predictor is run on both the canonical protein and the alternative isoform, and the evidence shown is the difference between them: the differential region against the shared core, or the canonical start against the alternative start. A metric in isolation is never the basis for a call.
  3. Score — the comparison is reduced to ✓ / ✗ / – against a fixed threshold. A criterion whose inputs could not be computed returns – (not evaluable) and is excluded from the denominator, so missing data never counts against an isoform.
  4. Directionality — for the constraint and disease axes the sign of the signal is what matters. Germline tolerance (F5) reads in the depletion direction: healthy-population (gnomAD) variation avoiding the unique region, plus high ESM-2 sequence constraint, argues the region is functionally load-bearing. Disease overlap (F6) reads in the enrichment direction: ClinVar / COSMIC variants concentrating in the unique region (per nucleotide) versus the shared core ties it to phenotype. These two databases are kept separate — gnomAD is a tolerance catalogue, never disease burden.

Thresholds & validation. A few cutoffs are principled anchors fixed on first principles — strong purifying selection (absolute phyloP ≥ 2.0) for E3, the disease-density zero-point (enrichment ≥ 1.0) for F6, reproducibility across ≥ 3 cell lines for E4, and the structure-confidence floor (pLDDT ≥ 0.70) for F1. The remaining cutoffs are provisional and pending calibration on a genome-wide run; the curated gene set shown here validates the logic of each criterion, not the exact numeric thresholds, which are deliberately not tuned to make a small reviewer-picked set look good.
